# Framework Rules

## Architecture

- Follow layered automation architecture.
- Keep framework modular.
- Separate Web, API, and Mobile layers.

## Design Patterns

- Use Page Object Model (POM).
- Use reusable utility classes.
- Keep driver logic centralized.

## Execution Rules

- Maintain Smoke and Regression suites.
- Keep CI/CD compatibility.
- Maintain reusable reporting logic.

## Reporting

- Use Extent Reports.
- Capture screenshots for failures.
- Maintain clean execution logs.
